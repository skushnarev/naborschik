# Недокументированное API Obsidian

Плагин опирается на один метод вне официального API: `MenuItem.setSubmenu()`.

## Что известно

- На Obsidian 1.15.0 метод работает при вызове без аргумента: сам создаёт подменю и возвращает `Menu`. Аргумент `Menu` не принимает.
- Официальной документации и типа в пакете `obsidian` нет.
- Поведение может измениться в новых версиях.

## Как это устроено в коде

- Тип объявлен необязательным через расширение модуля `obsidian` в `src/plugin/obsidian.d.ts`.
- Вызов изолирован в `src/plugin/menu.ts`.
- Перед вызовом идёт проверка `typeof item.setSubmenu === "function"`.
- Если метода нет, меню получает плоские пункты верхнего уровня с теми же действиями.

## Правило

Недокументированное API сверять по рабочим плагинам и живому рантайму, а не по памяти, типам или статьям.

- Найти, как метод вызывают существующие плагины, и повторить рабочий вызов.
- Проверить вызов в живой версии Obsidian, на которой работает плагин, и записать эту версию. `minAppVersion` в манифесте это нижняя граница, а не проверенная версия.
- Объявить метод необязательным и держать вызов в одном месте.
- Оставить откат, который не требует метода.
- Записать наблюдение и версию в заметку прогона или задачу.

Тип в `obsidian.d.ts` это только объявление для компилятора, а не доказательство поведения. Источник истины - рабочий плагин и рантайм.
