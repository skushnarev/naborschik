# Живой прогон 1: механика плагина

Дата: 2026-11-24
Платформа: macOS, Obsidian 1.15.0.
Хранилище: `LexxLog`, плагин поставлен симлинком через `make plugin-link`.
Вход: `Конвертер для постов/test.md`, выделение с шестой строки, после frontmatter и H1.

## Что подтвердилось

- Плагин `naborschik` 0.0.1 появился в списке сторонних плагинов и включается.
- Три команды палитры копируют свой префикс: `Для vc.ru`, `Для Дзена`, `Для Смартлаба`. Проверено на слове «Границы», на заголовке `## 2. Границы MVP` и на строке `> **Дата:** 2026-11-23`.
- Подменю «Копировать для ...» открывается и содержит три пункта.
- Пункт `vc.ru` копирует префикс, пустую строку и выделение без изменений.
- Заглушка не конвертирует Markdown: в буфере остаются `![[...]]`, `**жирный**`, `> [!note]`, `~~~js` и таблица. Это ожидаемо, конвертер подключается следующим эпиком.
- Плагин пережил несколько перезагрузок через переключение и `Cmd+R`.

## Что не проверялось

- Пункты `Дзен` и `Смартлаб` из меню: живой клик был только по `vc.ru`.
- Копирование без выделения: должна уйти заметка целиком, вместе с frontmatter и H1, потому что заглушка ничего не вырезает.
- Пустая заметка: ожидается уведомление «Нечего копировать» и нетронутый буфер.
- Уведомление после копирования: площадка и число символов.
- Вставка в черновики vc.ru, Дзена и Смартлаба: отложена до эпика конвертера, заглушка ничего не преобразует, а буфер системный.

## Открытые вопросы из спеки

- `setSubmenu()` на 1.15.0 работает при вызове без аргумента и возвращает меню. Официального API нет, поведение может измениться в новых версиях.
- Формат уведомления глазами не подтверждён, ждёт проверки.
