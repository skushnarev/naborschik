## Проблема

CL-01 перевёл `bin/make-golden.mjs` на `src/`, но генератор остался частично ручным и незащищённым.

- Вместо реестра `PLATFORMS` из `src/platforms/index.ts` генератор импортирует три адаптера поимённо и держит три параллельных массива `vcruSingle`, `dzenSingle`, `smartlabSingle`. Новая площадка требует правок в четырёх местах, хотя README называет `PLATFORMS` единственной точкой регистрации.
- В цикле одиночных кейсов `{ warnings: [...document.warnings] }` создаётся и выбрасывается: предупреждения адаптеров никуда не попадают, а копия массива создаёт ложное впечатление, что они учитываются.
- `article.expected.json` пишется из `doc` после трёх прогонов адаптеров. Сейчас адаптеры документ не мутируют, но порядок хрупкий: будущая мутация протечёт в эталон разбора.
- `for (const markdown of singleCases)` затеняет внешнюю `markdown`, а `Makefile` пишет «из src» вместо `src/`.
- README в разделе «Как добавить площадку» не упоминает `make golden`, поэтому после нового адаптера фикстуры не пересобираются.
- Генератор вне `tsconfig.include` и не запускается в `make check`. Переименование адаптера или смена сигнатуры `convert` уронят `make golden` молча, до первого ручного запуска.

## Что сделать

- Переписать `bin/make-golden.mjs` на `PLATFORMS`: один цикл по реестру, имя фикстуры выводится из `adapter.id`, без хардкода трёх площадок и параллельных массивов.
- Писать `article.expected.json` из `parse` до конвертации, а контекст предупреждений создавать свежим на каждый вызов, без мёртвых копий.
- Убрать затенение `markdown`.
- Дописать в README шаг про `make golden` в «Как добавить площадку» и поправить формулировку в `Makefile`.
- Добавить дешёвую защиту от молчаливой поломки генератора: тест или проверка в `make check`, которая запускает генератор во временном каталоге и сравнивает выход с фикстурами, не трогая рабочее дерево.

## Приёмка

- `make golden` даёт пустой diff.
- `make check` зелёный и ловит поломку импорта или сигнатуры в генераторе.
- Новая площадка, добавленная в `PLATFORMS`, получает golden-фикстуры без правки генератора.
- README и `Makefile` не расходятся с кодом.
- Выходы трёх площадок не меняются, версия плагина не растёт: сборка `dist/` не меняется.
