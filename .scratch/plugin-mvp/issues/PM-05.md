## Проблема

Смартлаб принимает безопасный HTML со своими правилами: H2 вырезается, `code` внутри `pre` показывается текстом. Нужен третий выход на том же разборе.

## Что сделать

- Адаптер Смартлаба по проверенному `toSmartlabHtml`: H2 в `<h3>`, H3 в `<h4>`, код в `<pre>` без `<code>`, таблица `<table>` с `thead` и `tbody`, разделитель `<hr>`, без классов, `id` и стилей.
- `plain` это читаемый текст без тегов.
- Добавить площадку в реестр с подписью и иконкой.
- Golden-тесты на фикстурах.

## Приёмка

- Пункт Смартлаба есть в меню и палитре.
- HTML совпадает с эталоном, лишних атрибутов нет.
- Заголовки уходят как h3 и h4, код без `code`.
- Выходы vc.ru и Дзена не изменились.
- `make check` зелёный.
