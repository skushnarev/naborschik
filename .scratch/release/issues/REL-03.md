## Проблема

Релиз `0.1.6` уже опубликован: в нём есть `main.js` и `manifest.json`, установка через BRAT проверена в чистом хранилище. Но README по-прежнему описывает только `make plugin-link` для автора. Человек без репозитория и Node не понимает, откуда взять плагин, куда положить файлы и как включить его в Obsidian. В каталоге Community плагина нет, `LICENSE` отсутствует.

## Что сделать

- Добавить в README установку из релиза: скачать `main.js` и `manifest.json`, положить в `<хранилище>/.obsidian/plugins/naborschik`, включить плагин.
- Добавить установку через BRAT со ссылкой на репозиторий и отметить, что BRAT скачивает те же артефакты.
- Указать в README `isDesktopOnly`, минимальную версию Obsidian и то, что плагин не грузит картинки на площадки.
- Добавить `LICENSE` MIT и указать лицензию в README.
- Сверить `manifest.json` с требованиями каталога: `id` из строчных букв и дефисов, без `obsidian`; `name` без `Obsidian` и `Plugin`; `description` до 250 символов с точкой; `author`; `minAppVersion`; `isDesktopOnly`. `versions.json` текущими требованиями не нужен.
- Проверить установку на чистом хранилище. BRAT уже проверен на `0.1.6`; ручную установку либо прогнать, либо явно записать, что она использует те же артефакты.
- Подать плагин в каталог Community: community.obsidian.md, вход по аккаунту Obsidian, привязка GitHub, добавление плагина. Пройти автоматическое ревью и исправить замечания.
- Записать решение о подаче и результат ревью.

## Приёмка

- Человек без доступа к репозиторию ставит плагин по README и запускает команду копирования.
- Установка через BRAT работает на релизе `0.1.6`.
- `LICENSE` лежит в корне, лицензия указана в README.
- Требования каталога проверены, пропуски названы.
- Плагин подан в community.obsidian.md; автоматическое ревью пройдено или замечания записаны.
- README не обещает загрузку картинок и мобильную версию.
- `make docs-check` зелёный.

## Заметки

- Релиз `0.1.6` отдаёт `main.js` и `manifest.json`, их хеши совпадают с локальным `dist/`. После тега в `main` только `docs` и `chore`.
- BRAT проверен в отдельном чистом хранилище: плагин `0.1.6` установился и включился.
- Ручную установку отдельно не проверяли: BRAT скачал те же артефакты из релиза.
- Текущие требования каталога не требуют `versions.json`. Подача идёт через community.obsidian.md, не через PR в `obsidian-releases`.
- README, `LICENSE` и спека обновлены. `manifest.json` сверен с требованиями: `id`, `name`, `description`, `author`, `minAppVersion` и `isDesktopOnly` проходят.
- Осталось человеческое действие: вход в community.obsidian.md, привязка GitHub, добавление плагина и прохождение автоматического ревью.
