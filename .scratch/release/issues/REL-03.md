## Проблема

README описывает только `make plugin-link` для автора. Человек без репозитория и Node не понимает, откуда взять плагин, куда положить `main.js` и `manifest.json` и как включить его в Obsidian. Для BRAT и каталога Community Plugins нужны отдельные требования, которые сейчас нигде не собраны.

## Что сделать

- Добавить в README раздел установки из релиза: скачать `main.js` и `manifest.json`, положить в `<хранилище>/.obsidian/plugins/naborschik`, включить плагин.
- Добавить установку через BRAT с ссылкой на репозиторий.
- Указать `isDesktopOnly`, минимальную версию Obsidian и то, что плагин не грузит картинки на площадки.
- Собрать чеклист Community Plugins: публичный репозиторий, `LICENSE`, корректные `id`, `name`, `author`, `description`, `manifest.json` в корне, релиз с `main.js` и `manifest.json`, README без секретов.
- Проверить инструкцию на чистом хранилище или второй машине.
- Решить, подаёмся в каталог сейчас или откладываем до стабильного релиза, и записать решение.

## Приёмка

- Человек без доступа к репозиторию ставит плагин по README и запускает команду копирования.
- Установка через BRAT работает или явно отложена с причиной.
- Чеклист Community Plugins заполнен, пропуски названы.
- README не обещает загрузку картинок и мобильную версию.
- `make docs-check` зелёный.

## Вне рамок

- Сама подача в каталог, если чеклист не пройден.
- Маркетинговые скриншоты и видео.
- Публикация через API площадок.
