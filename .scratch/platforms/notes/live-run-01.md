# Живой прогон 1: Дзен и Смартлаб

Дата: 2026-11-23
Статус: ждёт проверки в черновиках.
Вход: одна реальная статья из Obsidian, лучше `010` или `016`.
Метод: открыть `prototype/index.html`, выбрать площадку, нажать «Скопировать» и вставить в визуальный редактор.

## Что проверить

Для каждой площадки пройти одни и те же элементы:

| Элемент | Ожидание | Факт | Решение |
|---|---|---|---|
| H2 | заголовок | | |
| H3 | подзаголовок | | |
| Абзац с `b`, `i`, ссылкой | разметка на месте | | |
| UL и OL | нативные списки | | |
| Вложенный список | плоский список с `↳` | | |
| Цитата | blockquote | | |
| Код | Дзен: цитата. Смартлаб: `pre/code` | | |
| Таблица | Дзен: список пар. Смартлаб: `table` | | |
| Разделитель | Дзен: `* * *`. Смартлаб: `hr` | | |
| Картинка | строка `![[...]]`, замена ручная | | |
| Экранирование | `<script>` виден текстом | | |

## Отдельно проверить

- Пришёл ли HTML размеченным или редактор вставил теги текстом.
- Не склеил ли редактор соседние абзацы.
- Не потерялись ли ссылки и пустые строки.
- Не вырезал ли санитайзер `pre`, `code`, `table` и `hr`.
- Как выглядит длинная статья: нет ли заметной задержки.

## Итог

Заполняется после проверки. Сюда же решения: оставить тег, деградировать или отказаться от элемента.
