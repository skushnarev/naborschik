# Живой прогон 1: Дзен и Смартлаб

Дата: 2026-11-23
Статус: Дзен проверен, Смартлаб ждёт проверки.
Вход: пример из прототипа и реальная статья `016`.
Метод: открыть `prototype/index.html`, выбрать площадку, нажать «Скопировать» и вставить в визуальный редактор.

## Что проверить

Для каждой площадки пройти одни и те же элементы:

| Элемент | Ожидание | Факт | Решение |
|---|---|---|---|
| H2 | заголовок | | |
| H3 | подзаголовок | | |
| Абзац с `b`, `i`, ссылкой | разметка на месте | | |
| UL и OL | нативные списки | | |
| Вложенный список | плоский список с `↳` | | |
| Цитата | blockquote | | |
| Код | Дзен: цитата. Смартлаб: `pre/code` | | |
| Таблица | Дзен: список пар. Смартлаб: `table` | | |
| Разделитель | Дзен: `* * *`. Смартлаб: `hr` | | |
| Картинка | строка `![[...]]`, замена ручная | | |
| Экранирование | `<script>` виден текстом | | |

## Отдельно проверить

- Пришёл ли HTML размеченным или редактор вставил теги текстом.
- Не склеил ли редактор соседние абзацы.
- Не потерялись ли ссылки и пустые строки.
- Не вырезал ли санитайзер `pre`, `code`, `table` и `hr`.
- Как выглядит длинная статья: нет ли заметной задержки.

## Дзен: результат

| Элемент | Факт |
|---|---|
| Вставка HTML | разметка пришла, теги текстом не вставились |
| H2 и H3 | заголовки на месте |
| Абзац с `b`, `i`, ссылкой | жирный, курсив и ссылка сохранились |
| UL и OL | нативные списки |
| Вложенный список | плоский список с `↳` |
| Цитата и callout | blockquote, заголовок жирным |
| Код | цитата с сохранением строк, читается нормально |
| Таблица | список пар «заголовок: значение» |
| Разделитель | текст `* * *` |
| Картинка | строка `![[...]]`, замена ручная |
| Ссылка на заметку | осталась текстом с алиасом |

Реальная статья `016` встала целиком, микроразметка с жирным в тексте сохранилась. Это тот случай, где раньше была ручная работа.

Копирование из черновика Дзена обратно отдаёт только текст без разметки. Это ограничение редактора, а не нашего выхода. Для Смартлаба надо брать HTML из прототипа, а не копировать из Дзена.

Код цитатой принят для первого прохода. Если на длинных листингах будет мешать, заведём отдельную задачу на другой вид деградации.

## Итог

Дзен принят. Смартлаб ещё не проверен: ждём вставку и список выживших тегов.
