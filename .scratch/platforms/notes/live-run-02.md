# Живой прогон 2: фото

Дата: 2026-11-24
Вход: пример из прототипа с `![[star.png|64]]` (16x16) и `![[BLG016_top.jpg|800]]`.
Метод: открыть `prototype/index.html`, выбрать площадку, нажать «Скопировать» и вставить в редактор черновика.

## Смартлаб

Картинка принята. Площадка перезалила data URI к себе и отдала её как webp:

```html
<a class="imgpreview" href="/uploads/2026/images/30/56/96/2026/11/24/9ccc96.png"><img src="/uploads/2026/images/30/56/96/2026/11/24/d3dc4a.webp"></a>
```

Остальная разметка тоже выжила: `h3` и `h4`, списки, цитата, `table`, `pre`, `hr`. Вики-ссылка осталась текстом `[[Папка/Заметка|алиас]]`, как и задумано.

Вывод: путь `data URI` для Смартлаба рабочий. Размер 16x16 площадку устроил.

## Дзен

Картинка отклонена. Редактор показал «Загружено с ошибкой» и сообщение:

```text
Изображение должно быть не менее 300 пикселей в ширину
```

16x16 не проходит по ширине. Для повторного прогона добавлена `prototype/fixtures/gray.png` 320x320. Серая заливка сжимается до 465 байт, data URI занимает 642 символа. Пример теперь использует `![[gray.png|300]]`.

Остальная разметка в Дзене пришла как раньше: заголовки, списки, цитата, таблица списком, разделитель. Ошибка относилась только к картинке.

Повторный прогон с `gray.png` 320x320 прошёл: серый квадрат появился в редакторе, ошибки нет. Поле описания осталось пустым, это нормально.

Вывод: Дзен принимает картинку из data URI, если её ширина не меньше 300 пикселей.

## vc.ru

Выход содержал нативный блок:

```text
[media:{"title":null,"items":[{"title":"star.png","image":{"type":"image","data":{"uuid":"d5b9fb1f-6c25-5923-a2d6-838d62c9503e","width":16,"height":16,"size":106,"type":"png","color":"e64626","hash":"","external_service":[],"base64preview":"..."}}}]}]
```

vc.ru принял структуру и создал блок фото с подписью `star.png`, но вместо картинки показал заглушку «Not Found». Остальные блоки встали нормально.

Вывод: формат `[media:...]` верный, но `uuid` должен быть настоящим. Условный `uuid` площадка не разрешает, а `base64preview` это только превью 10x10, его недостаточно. Нужна загрузка файла на сервер vc.ru и `uuid` из ответа. Это отдельная задача PL-13.

## Итог

- Смартлаб: data URI принят, картинка перезалита площадкой.
- Дзен: data URI принят после увеличения картинки до 320x320, серый квадрат появился.
- vc.ru: структура `[media:...]` принята, но без настоящего `uuid` фото не появляется.
