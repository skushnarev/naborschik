## Проблема

PL-14 показал: `<img src="data:...">` внутри HTML работает для Дзена и Смартлаба, но не для vc.ru. На vc.ru картинка появляется при вставке, а после обновления страницы черновика исчезает. Поэтому для vc.ru строка `![[...]]` остаётся текстом, фото автор вставляет вручную.

Для Дзена и Смартлаба путь рабочий: Дзен показывает нативный блок с полем описания, Смартлаб перезаливает картинку к себе. В прототипе карта изображений это фикстура. В плагине картинку нужно читать из хранилища Obsidian и собирать data URI.

## Что сделать

- Читать файл картинки из хранилища по имени из `![[...]]` и собирать data URI на стороне плагина. Конвертер остаётся чистым.
- Передавать карту `{ src }` в `toBlocks` только для Дзена и Смартлаба. Для vc.ru карта не нужна: строка остаётся текстом.
- Проверить требование Дзена по ширине: не меньше 300 пикселей. При необходимости уменьшать или дополнять картинку.
- Проверить пустой `<a class="imgpreview">`, который остаётся рядом с картинкой в Смартлабе, и сохранение после перезагрузки.
- Не добавлять переключатель в прототип и не ходить в API площадок.

## Приёмка

- Дзен показывает картинку из хранилища нативным блоком с полем описания, блок переживает обновление страницы.
- Смартлаб показывает картинку из хранилища, пустой якорь не мешает публикации.
- vc.ru получает строку `![[...]]` текстом, замена ручная.
- Конвертер по-прежнему чистые функции без сети и Obsidian API.
- Токены, cookies и личные данные не попадают в репозиторий.
