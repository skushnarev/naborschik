## Проблема

Прототип умеет только vc.ru. Чтобы проверить Дзен и Смартлаб на живых черновиках, нужен один вход и переключатель выхода, иначе придётся держать три копии страницы.

## Что сделать

- Добавить переключатель `vc.ru`, `Дзен`, `Смартлаб`.
- Считать все три выхода при каждом изменении Markdown.
- Показывать выбранный выход во вкладке Payload.
- Менять подпись кнопки копирования под площадку.
- Для Дзена и Смартлаба копировать HTML через Clipboard API с `text/html` и `text/plain`.
- Для vc.ru оставить текущее копирование `text/plain`.
- Обновить подсказки и статистику под выбранную площадку.

## Приёмка

- Переключение площадки не теряет введённый Markdown и не пересчитывает блоки заново.
- Кнопка копирования кладёт ровно тот выход, который показан.
- vc.ru копируется как раньше.
- Если `ClipboardItem` недоступен, HTML копируется текстом и показывается предупреждение.
