# naborschik

Плагин для Obsidian под рабочим названием `naborschik`: превращает Markdown статьи в блоки для vc.ru и HTML-фрагменты для Дзена и Смартлаба.

Сейчас в плагине работают vc.ru, Дзен и Смартлаб: выделение или заметка целиком разбираются и попадают в буфер готовыми блоками.

## Что внутри

- `prototype/` - одноразовый конвертер: textarea, выбор площадки, предпросмотр и 40 самопроверок.
- `prototype/obsidian/` - плагин-заглушка: команды палитры, префикс площадки, буфер.
- `.scratch/vc-mvp/` - спека гипотезы vc.ru и задачи эпика.
- `.scratch/platforms/` - спека HTML-выходов для Дзена и Смартлаба.
- `.scratch/plugin-prototype/` - спека и задачи механики плагина.
- `.agents/skills/` - вендор скиллов `mattpocock/skills`.
- `.agents/commands/` - слэш-команды, собранные из скиллов.
- `docs/` - процессы, решения, заметки по скиллам.
- `bin/` - проверки задач, документации, чистоты ядра и сборка golden.

## Прототип

```bash
make prototype
```

Откроется `prototype/index.html`. Дальше:

1. Выделить статью в Obsidian без H1, скопировать.
2. Вставить Markdown в левое поле.
3. Выбрать площадку: `vc.ru`, `Дзен` или `Смартлаб`.
4. Проверить выход и нажать «Скопировать».
5. Для vc.ru поставить курсор в пустой текстовый блок и вставить. Для Дзена и Смартлаба вставить HTML в визуальный редактор.
6. Заголовок статьи вписать в поле заголовка вручную.

Если открыть файл двойным кликом, тоже работает: `marked` лежит рядом в `prototype/vendor/`.

## Плагин

```bash
npm install
make plugin-link VAULT=/путь/к/хранилищу
```

Цель собирает плагин в `dist/` и ставит симлинк `<хранилище>/.obsidian/plugins/naborschik` на эту папку. Дальше в Obsidian включить сторонние плагины и `naborschik`. После правок выполнить `make build` или держать `make dev`, потом перезагрузить плагин или нажать `Cmd+R`.

В плагине работают vc.ru, Дзен и Смартлаб. Команды `Копировать для vc.ru`, `Копировать для Дзена` и `Копировать для Смартлаба`, а также пункты меню разбирают выделение или заметку целиком, отбрасывают frontmatter и H1 и кладут в буфер готовый выход без префикса. vc.ru получает блоки `[tool:...]`. Дзен получает HTML: код становится цитатой, таблица списком пар, картинка с `src` тегом `img`. Смартлаб получает HTML с H2 как h3, H3 как h4, кодом в `pre` без `code` и таблицей. У HTML-выходов `plain` остаётся читаемым текстом без тегов. Одиночный блок vc.ru уходит читаемым текстом, пустая заметка буфер не трогает, уведомление показывает число символов и предупреждений. Если Obsidian не умеет подменю, вместо него появляются плоские пункты.

## Задачи

Задачи и спеки это markdown-файлы в `.scratch/`. Одна фича или эпик - одна директория, спека в `spec.md`, задачи в `issues/`. Статус хранится во front matter задачи, а не в тексте документа.

```bash
make status
make status ARGS="--all"
make status ARGS="--area vc-converter"
make status ARGS="--check"
```

Правила и формат: `docs/agents/issue-tracker.md`.

## Проверки

```bash
npm install
make docs-check
make core-check
make test
make test-proto
make check
make hooks
```

`make test` гоняет тесты плагина, `make test-proto` - тесты прототипа. `make core-check` проверяет, что ядро не импортирует Obsidian. `make check` добавляет к ним типы, оба набора тестов и сборку. `make hooks` ставит pre-commit с `make check`.

`docs-check` проверяет front matter, ссылки, циклы блокировок и запрещает чеклисты и статусные таблицы в нарративных документах.

## Скиллы

Скиллы лежат в `.agents/skills/`, команды в `.agents/commands/`. Адаптер OpenCode это симлинк `.opencode/commands -> ../.agents/commands`, его создаёт одна команда после клонирования:

```bash
make agents
```

Источник и порядок обновления: `docs/skills/ADOPTION.md`.
