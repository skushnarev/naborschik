# Плагин-заглушка

Прототип плагина Obsidian без сборки и без конвертера. Задача - проверить механику: Obsidian отдаёт выделение, буфер принимает текст, уведомление показывается. Разбор Markdown и площадки подключаются следующим эпиком.

## Что делает

Правый клик по выделению открывает пункт «Копировать для ...» с подменю из трёх площадок: `vc.ru`, `Дзен`, `Смартлаб`. Те же действия продублированы тремя командами в палитре команд:

- `Копировать для vc.ru`
- `Копировать для Дзена`
- `Копировать для Смартлаба`

Каждый пункт и каждая команда кладут в буфер `text/plain`: строку `Для <площадка>`, пустую строку и выделение как есть. Пустое выделение заменяется заметкой целиком. Если в заметке нет текста, буфер не меняется и показывается «Нечего копировать».

Префикс временный: он показывает, какая команда сработала. Когда подключим конвертер, префикс уйдёт.

## Установка

```bash
make plugin-link VAULT=/путь/к/хранилищу
```

Цель создаёт симлинк `<хранилище>/.obsidian/plugins/naborschik` на эту папку. Путь к хранилищу в репозитории не хранится, его нужно передавать каждый раз.

Дальше в Obsidian: выключить ограниченный режим, если он включён, открыть сторонние плагины и включить `naborschik`.

## Перезагрузка

После правок `main.js` переключить плагин в настройках или нажать `Cmd+R`. Если Obsidian закэшировал файл и правки не подхватились, полностью перезапустить приложение. Плагин Hot Reload не нужен: файлов мало, перезагрузок тоже.

## Откат

```bash
rm <хранилище>/.obsidian/plugins/naborschik
```

Если подменю в меню редактора не отрисуется, в `main.js` поставить `USE_SUBMENU = false` и перезагрузить плагин. Вместо подменю появятся три плоских пункта верхнего уровня ровно с теми же действиями. Исход проверки попадёт в заметку прогона и в «Итог» задачи `OB-03`.

Меню файла в проводнике и режим чтения не поддержаны: подменю живёт только в редакторе.

## Ограничения

- Конвертера нет, выход это сырое выделение с префиксом.
- Все площадки получают `text/plain`, HTML не пишется.
- Настроек, `loadData` и записи файлов нет.
- Только десктоп: `isDesktopOnly` включён.
- Версия для проверки - Obsidian 1.15.0.
