# Глоссарий

Термины проекта. Если термин нужен в спеке, задаче или коде, писать его так, как здесь. Синонимы, которые вводят
путаницу, вынесены в последнюю колонку.

| Термин           | Значение                                                                    | Не путать                        |
|------------------|-----------------------------------------------------------------------------|----------------------------------|
| Naborschik       | Название плагина: набирает статью и раскладывает её по блокам vc.ru         | Не название статьи и не площадка |
| Статья           | Markdown-файл в Obsidian, который публикуется на vc.ru, Дзене или Смартлабе | Не черновик в редакторе площадки |
| Блок             | Один элемент статьи: заголовок, абзац, список, цитата, разделитель          | Не абзац в Markdown              |
| Документ         | Общая модель статьи после `parse`: блоки и предупреждения                    | Не Markdown и не payload         |
| Payload          | Данные буфера: `plain` и необязательный `html`                              | Не Markdown и не Obsidian-блок   |
| Plain            | Читаемый текст без тегов, запасной выход для HTML-площадок                  | Не Markdown                      |
| Tool-блок        | Блок в `plain` для vc.ru вида `[text:{...}]`, `[header:{...}]`              | Не блок Obsidian                 |
| Плоский путь     | Вставка одного блока vc.ru обычным текстом, без `[tool:...]`                | Не режим конвертера              |
| Адаптер площадки | Модуль в `src/platforms/`, превращает `Document` в payload                  | Не парсер и не плагин            |
| Реестр площадок  | Упорядоченный список адаптеров в `src/platforms/index.ts`                   | Не настройки плагина             |
| Предупреждение   | Запись о деградации разбора или конвертации                                 | Не ошибка и не пустой результат  |
| Резолвер картинок | Карта вставок `![[...]]` в data URI и ширину, собранная обвязкой до `parse` | Не загрузка на площадку          |
| HTML-мост        | Ветка `text/html` для vc.ru и Windows, отложена                             | Не HTML-выход Дзена и Смартлаба  |
| Конвертер        | Ядро из чистых функций: `parse` собирает `Document`, адаптер площадки превращает его в payload | Не плагин целиком                |
| Callout          | Цитата Obsidian с маркером `[!type]`                                        | Не обычная цитата                |
| Вики-ссылка      | Ссылка Obsidian вида `[[Заметка\|алиас]]`                                    | Не URL и не Markdown-ссылка      |
| Гипотеза         | Статья переносится одним копированием с минимумом правок                    | Не гарантия качества верстки     |
| Плагин-заглушка  | Исторический прототип без конвертера: команды, префикс, буфер, код удалён    | Не продакшен-плагин              |
| Префикс площадки | Строка `Для vc.ru`, которую добавляла заглушка; в плагине убрана             | Не заголовок статьи              |
| Живая проверка   | Ручной прогон в Obsidian или на площадке, отдельная задача с `kind: verification` | Не юнит-тест                    |
| Версия плагина   | Одно значение вида `0.1.5` в `package.json`, `package-lock.json` и `manifest.json`; Obsidian читает его из `manifest.json` | Не тег релиза                    |
| Тег релиза       | Метка коммита вида `0.1.5` без префикса `v`, совпадающая с версией плагина  | Не версия плагина                |
| Релиз            | Опубликованная на GitHub версия плагина с тегом и артефактами               | Не коммит и не тег               |
| Артефакт релиза  | Файлы `main.js` и `manifest.json`, приложенные к релизу; `styles.css`, если он есть в сборке | Не исходники в `dist/`           |
| Эпик             | Группа задач с одной спекой, например `plugin-mvp` или `release`            | Не задача                        |
| Спека            | `spec.md` эпика: цель, границы, инварианты, DoD                             | Не план проекта                  |
| Задача           | Один файл в `.scratch/<эпик>/issues/` с front matter                        | Не пункт чеклиста                |
| Milestone        | Горизонт задачи: `mvp`, `next`, `later`                                     | Не приоритет и не severity       |
